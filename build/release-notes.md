# a8a 업데이트 안내

이번 버전은 **환경변수 값 오류 수정** Windows 릴리즈입니다.

- 이름에 하이픈(`-`)이 들어간 환경변수가 **`NaN`으로 표시되고 실제 요청에도 `NaN`으로 전송되던 문제를 해결**했습니다. `ocp-apim-subscription-key`처럼 하이픈이 있는 키를 쓰셨다면 API 인증이 실패했을 수 있습니다.
- 원인은 키 이름의 하이픈을 **뺄셈으로 잘못 해석**한 것이었습니다. 이제 환경변수 목록에 있는 이름은 언제나 그 값을 그대로 사용합니다.
- 값이 없는 환경변수는 **`NaN` 대신 "값 없음"으로 표시**되고, `{{변수명}}` 표기가 그대로 남습니다. 빈 값이 모르는 사이에 전송되지 않습니다.
- `{{1+2}}` 같은 계산식 사용은 종전과 동일하게 동작합니다.
