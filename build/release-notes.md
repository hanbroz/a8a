# a8a 업데이트 안내

이번 버전은 **선택 창 검색·복사** Windows 릴리즈입니다.

- SELECT 선택 창에서 **Ctrl+F(맥은 Cmd+F)로 검색**할 수 있습니다. key, JSONPath, 값을 모두 찾으며 일치한 부분이 노란색으로, 현재 위치가 초록색으로 표시됩니다.
- 검색 후 **Enter로 다음 결과, Shift+Enter로 이전 결과**로 이동합니다. `< >` 버튼과 `3/12` 형태의 카운터도 함께 제공합니다. Esc는 검색어를 지웁니다.
- 찾은 항목이 접혀 있으면 **상위 경로가 자동으로 펼쳐지고** 해당 위치로 화면이 이동합니다.
- JSON 목록의 각 줄에 **복사 버튼**이 생겼습니다. 값이 객체나 배열이면 보기 좋게 정리된 JSON으로 복사되며, 맨 위 `$` 줄을 복사하면 전체 JSON이 복사됩니다.
- Table 보기에서도 같은 방식으로 행을 검색할 수 있습니다.
