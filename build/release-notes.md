# a8a 업데이트 안내

이번 버전은 **선택 창 검색 속도 개선** Windows 릴리즈입니다.

- 큰 JSON에서 **검색어를 입력할 때 창이 멈추던 문제를 해결**했습니다. 이제 글자를 치는 동안에는 아무 계산도 하지 않습니다.
- 검색은 **입력 후 Enter를 눌러야 실행**됩니다. 같은 검색어에서 Enter를 다시 누르면 다음 결과로, Shift+Enter는 이전 결과로 이동합니다.
- 검색 결과가 접혀 있으면 **지금 보고 있는 항목의 경로만** 펼칩니다. 이전처럼 트리 전체가 한꺼번에 펼쳐져 느려지지 않습니다.
- Esc 키나 `X` 버튼을 누르면 입력한 검색어와 검색 결과가 함께 지워집니다.
- Ctrl+F(맥은 Cmd+F)로 검색창에 바로 커서를 놓는 기능, 각 줄의 복사 버튼은 그대로입니다.
