# a8a 업데이트 안내

이번 버전은 **ESC로 창 닫기 + 화면 전환 오류 수정** Windows 릴리즈입니다.

- **모든 레이어 팝업을 ESC 키로 닫을 수 있습니다.** 모달을 자주 열고 닫을 때 X 버튼까지 마우스를 옮기지 않아도 됩니다. X 버튼에 마우스를 올리면 "ESC 키로 닫을 수 있습니다" 안내가 표시됩니다. 팝업이 겹쳐 있으면 **가장 위에 있는 창 하나만** 닫히므로, 모달 안에서 열린 확인창이나 전체화면 편집기가 먼저 닫힙니다.
- **노드 편집 모달은 저장하지 않은 변경이 있으면 확인창을 띄웁니다.** ESC나 X, 취소로 닫을 때 수정한 내용이 말없이 사라지지 않습니다. 저장 후 닫기는 확인창 없이 그대로 닫힙니다.
- **로그 화면을 보다가 다른 프로젝트를 선택하면 캔버스가 보입니다.** 전에는 빈 로그 화면이 그대로 남아 캔버스 내용이 모두 사라진 것처럼 보였습니다.
- **환경설정 값을 복사 버튼으로 복사할 수 있습니다.** 삭제 버튼 왼쪽 복사 버튼을 누르면 복사한 값이 그 행에 "복사됨" 알림으로 표시됩니다. 긴 토큰 값을 드래그로 선택하지 않아도 됩니다.
